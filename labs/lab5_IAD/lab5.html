ПІДГОТОВКА СЕРЕДОВИЩА ТА ДАНИХ

Для проведення кластерного аналізу використаємо вбудований набір даних state.x77, який містить статистичні показники 50 штатів США. Дослідження охоплюватиме демографічні, соціально-економічні та географічні характеристики штатів.

install.packages(c("tidyverse", "cluster"), repos = "https://cloud.r-project.org")
library(tidyverse)
library(cluster)

ВИБІР ОЗНАК ТА МАСШТАБУВАННЯ

Для кластеризації обрано вісім числових показників штатів США. Назви штатів використовуються як ідентифікатори, тому не включаються до матриці ознак.

Оскільки показники мають різні одиниці вимірювання та масштаби, перед кластеризацією виконаємо стандартизацію. Це дозволить уникнути переважного впливу показників із найбільшими числовими значеннями.

# Вибір числових ознак
X <- data |>
  select(-State)

# Перевірка даних

КЛАСТЕРИЗАЦІЯ МЕТОДОМ K-MEANS

Метод k-середніх (k-means) використовується для поділу штатів США на групи зі схожими характеристиками. Алгоритм формує кластери таким чином, щоб мінімізувати суму квадратів відстаней між об’єктами та центрами відповідних кластерів.

Для початкового дослідження використаємо три кластери.

# Побудова моделі k-means
set.seed(123)

km3 <- kmeans(Z, centers = 3, nstart = 30)

# Розмір кожного кластера
km3$size
