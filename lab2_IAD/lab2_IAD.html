8. Отримання даних із веб-джерела

Для Web Mining використано Wikipedia як зовнішнє веб-джерело. Дані отримуються програмно через REST API у форматі JSON. Для кожного виду пінгвінів буде отримано текстовий опис статті та адресу сторінки. Такий підхід дозволяє автоматизовано отримати текстові дані для подальшої підготовки та інтеграції.

species_pages <- c(
  adelie = "Adelie_penguin",
  chinstrap = "Chinstrap_penguin",
  gentoo = "Gentoo_penguin"
)

wiki_data <- lapply(names(species_pages), function(sp) {
  url <- paste0(
    "https://en.wikipedia.org/api/rest_v1/page/summary/",
    species_pages[[sp]]
  )
  
  data <- fromJSON(url)
  
  data.frame(
    species = sp,
    title = data$title,
    description = data$extract,
    wiki_url = data$content_urls$desktop$page
  )
}) %>%
  bind_rows()

10. Підготовка текстових даних

Текстові описи з веб-джерела очищуються від зайвих пробілів. Додатково визначається кількість слів у кожному описі. Це дозволяє перетворити текстову інформацію на кількісну ознаку для подальшого аналізу.

wiki_data <- wiki_data %>%
  mutate(
    description = str_squish(description),
    text_words = str_count(description, boundary("word"))
  )

11. Інтеграція даних

Локальні дані про пінгвінів об’єднуються з текстовими даними, отриманими з Wikipedia. Об’єднання виконується за спільним ключем species. У результаті кожне спостереження доповнюється описом відповідного виду та кількістю слів у ньому.

penguins_integrated <- penguins_clean %>%

13. Створення похідних ознак

Для розширення аналітичних можливостей створюються дві похідні ознаки. Перша — маса тіла пінгвіна в кілограмах. Друга — співвідношення довжини ласти до маси тіла. Ці показники дають змогу порівнювати фізичні характеристики пінгвінів у зручнішому для аналізу форматі.

penguins_integrated <- penguins_integrated %>%
  mutate(
    body_mass_kg = body_mass_g / 1000,
    flipper_mass_ratio = flipper_length_mm / body_mass_g
  )

15. Контрольна візуалізація

Для контролю результатів інтеграції побудовано діаграму середньої маси пінгвінів за видами. Візуалізація дозволяє порівняти фізичні характеристики різних видів після підготовки та об’єднання даних.

mass_by_species <- penguins_integrated %>%
  group_by(species) %>%
  summarise(
    mean_body_mass_kg = mean(body_mass_kg)
  )

ggplot(mass_by_species, aes(x = species, y = mean_body_mass_kg)) +
  geom_col() +
